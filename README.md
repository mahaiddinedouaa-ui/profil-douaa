- Nom animé lettre par lettre
- Fond de couleurs en mouvement
- Texte qui s'écrit tout seul

- Apparition des sections au défilement
- Adapté au mobile

## Structure du projet

```
portfolio/
├── index.html   # Structure de la page

└── README.md
```

## Lancer le projet

1. Télécharger les fichiers.
2. Ouvrir `index.html` dans un navigateur.

Aucune installation nécessaire.

## Ajouter un projet

1. Ajouter une image dans le dossier du projet.
2. Copier un bloc `<article class="card tilt reveal">…</article>` dans `index.html`.
3. Modifier l'image, le titre, la description et le lien.
